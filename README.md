# question-book
I built a search engine that runs on html 

# The Core idea 
The Core idea was that i wanted a search engine that is a mix of Google and Perplexity was you can choose to be either AI Focused or Just Like Old Internet with just links. There are no adds and it's Open Sourced and runs on HTML so you can easily customize it to your liking if you know how to code 

# Features
AI or Old Internet: You can choose if you want an AI focused search or just the old internet with links to actual websites
Real Websites: It connects to the internet and gives you real websites and links instead of just using a fake local search system
No Ads: There are no ads, popups or random shit trying to get your attention
Open Source: The whole thing is open sourced so you can look at the code and change it however you want
HTML Based: It runs as a HTML file so you don't need to install some massive program or run a server just to use it
Customisable: Because it's just HTML, CSS and JavaScript, you can change the design, search page and basically anything else if you know how to code
Simple Homepage: The homepage is designed like a digital question book instead of looking like another copy of Google
New Tabs: When you click on a result it opens the website in a new tab so you don't lose your search
Refresh = Home: Whenever you refresh the page it goes straight back to the homepage instead of keeping your previous search
No Account: You don't need to make an account or log into anything to use it
Made To Be Messed With: The idea is that you're supposed to be able to take the code, change it and make question-book your own
